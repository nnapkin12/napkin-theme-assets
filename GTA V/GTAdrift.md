## Stand Config Key Settings

```text
Model: [Drift Tune Model Code]
Tyres Mode: 1
```

* `Model`: Replace the standard model string with the matching drift model string e.g. "cypher"--->"driftcypher".
* `Tyres Mode: 1`: Sets tires to Low-Grip.
